# 律鉴 LawBench

律鉴是一个可本地运行的法律智能办案 MVP：支持账号与权限、案情分析、法规/案例检索、期限与费用计算、合同审查、案件管理、判后执行和用量审计。

默认使用 `Demo` 模式和小型可核验知识库，不需要模型密钥即可完成核心演示。真实模型可通过 OpenAI 兼容接口接入；Milvus 和 Elasticsearch 是可选增强，不影响基础启动。

> 所有法律分析仅供参考，不构成正式法律意见。法规效力和条文内容以权威机关最新公布文本为准。
